example

One view of the command instead of a collection of flag formats.

-h, --help
--help

Show this help and exit

example --help
-q, --quiet
--help

Suppress ordinary output

example --quiet
-o, --output <FILE>
--help

Write output to FILE

example --output <FILE>
--color <WHEN>
--help

Colorize output: auto, always, or never

example --color <WHEN>
--jobs <COUNT>
--help

Number of jobs to run

example --jobs <COUNT>
